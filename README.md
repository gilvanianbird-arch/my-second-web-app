# 架空病院 LP（コーディング作品）

🔗 **デモ：** https://gilvanianbird-arch.github.io/my-second-web-app/

架空の病院を題材にしたランディングページのコーディング作品です。  
医療機関に求められる「信頼感」と「わかりやすい導線」を意識して制作しました。

---

## 制作のポイント

- **信頼感のある配色・レイアウト**：落ち着いたカラーと余白設計で、患者・家族が安心できる雰囲気を演出
- **導線設計**：診療科・受診案内・アクセス情報へスムーズに誘導できるセクション構成
- **レスポンシブ対応**：スマートフォン・タブレット・PCの各サイズに対応

---

## 技術スタック

| カテゴリ | 技術 |
|--------|------|
| マークアップ | HTML5 |
| スタイリング | CSS3 |
| ホスティング | GitHub Pages |

---

## 工夫した点

- ファーストビューで病院名・診療時間・アクセスを一目で確認できるレイアウトを設計
- ナビゲーションは固定ヘッダーにし、どのセクションからでも目的の情報へ移動しやすくした
- 余白・行間を意識し、テキスト量が多い医療系コンテンツでも読みやすい設計を心がけた
